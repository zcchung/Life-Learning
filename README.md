# Life-Learning

终身学习仓库，用来记录人生阶段中生活与工作中遇到的可学习内容。

## 目标与范围
- 以 NLP / LLM 算法工程为当前主线，沉淀可复用的知识、代码与实践记录。
- 逐步覆盖读书记录、写作与内容管理，以及心理学、管理、投资等方向。
- 后续扩展算法落地的工程化能力与全栈开发知识，并以 Python 为主要实现语言。

## 目录结构
- `01-Tech/`：技术与工程主线（NLP/LLM、工程化、全栈与项目）。
- `02-Knowledge-Work/`：读书记录、写作与内容管理。
- `03-Mind-Business/`：心理学、管理、投资等。
- `04-Resources/`：书籍、课程、工具与数据集清单。
- `05-Templates/`：可复用的模板（文档、实验记录、项目结构等）。
- `06-Logs/`：阶段性学习日志与复盘。

## 使用建议
1. 新内容优先落在对应主题目录，并在子目录内补充 README 说明。
2. 每个主题建议包含：概念总结、关键链接、实践记录与复盘。
3. 长期维护时，可在 `06-Logs/` 中记录每周/每月进展。

## 约定
- 优先使用 Markdown 记录内容。
- 代码示例以 Python 为主，其他语言作为补充。
